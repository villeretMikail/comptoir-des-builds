Build Vignoble & Golf — Pygmalien

Le Vignoble et les Clubs de Golf sont obligatoires. L'Oiseau et les Bandages sont presque toujours là mais se remplacent. Pain de Savon, Textiles et Tentes de Luxe font gagner quand ils tombent.

Stats : Bazaar DB, patch 19.0 (hotfix du 8 octobre)

Ouvrir ce build dans l’outil

Le core

  • Vignoble (Vineyard) · Obligatoire
  • Clubs de Golf (Golf Clubs) · Obligatoire
  • Oiseau Uwashiwali (Uwashiwali Bird) · Moteur
  • Bandages · Moteur

Variante 1 : Le build visé

Les items de heal rapides comme le savon ou les bandages, les multicast comme l'oiseau ou encore les textiles qui peuvent charger rapidement le club de golf sont de très bonnes combinaisons avec ce build, tentes de luxe multiplie par deux le scaling de club de golf, ne pas jouer textile avec tentes de luxe si le club de golf est enchanté heal puisque textile ne charge pas les items de heal.

Elle ajoute :

  • Pain de Savon (Bar of Soap) · Key
  • Textiles · Key : Commence en Or : à viser en fin de run.
  • Tentes de Luxe (Luxury Tents) · Key : Commence en Or : à viser en fin de run.

Board type : Vignoble, Clubs de Golf, Textiles, Oiseau Uwashiwali, Bandages, Pain de Savon.

Peut rentrer

Des objets qui vont avec l'idée du build.

  • Fontaine (Fountain) · Option
  • Plantes Grasses (Succulents) · Option
  • Lavomatique (Hogwash) · Option

Comment le jouer

Le but est d'aller chercher les vignes et le club de golf, puis de trouver des sources de heal (ou de slow) qui vont faire scale club de golf, le lavomatique convertit chaque heal en slow et peut potentiellement rentrer dans toute variante.

Les étiquettes

  • Obligatoire : Le build n'existe pas sans.
  • Moteur : Presque toujours là, mais remplaçable.
  • Key : Rare, mais quand il est là, ça gagne.
  • Option : Une option quand il reste de la place.
