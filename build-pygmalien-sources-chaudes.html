Build Sources chaudes — Pygmalien

1 run : 8 victoires.

Ouvrir ce build dans l’outil

Le core

  • Private Hot Springs

Variante 1 : Ice Luge spam

Quand on a un camion de glace et un Ice Luge, surtout avec des ammos réduites, on peut faire de bonnes boucles de freeze qui déclenchent de façon décemment rapide les hot springs.

Elle ajoute :

  • Ice Luge · Moteur : Réduction de cd pour spam les sources chaudes

Peut rentrer dans cette variante :

  • Ice Cream Truck : Boucle de charge avec les bains

Board type : Private Hot Springs, Ice Luge, Ice Cream Truck, Stopwatch, Stopwatch, Icicle.

Peut rentrer

Des objets qui vont avec l'idée du build.

  • Badblocker : Si enchantement freeze et beaucoup d'items à +10 de value > multicast élevé qui charge bien sources chaudes
  • Stopwatch · Key : Gros freeze général bien pour les springs
  • Icicle : Instant charge au début du combat
  • Steam Ladle : Profite très bien du freeze

Comment le jouer

Chercher des items qui freeze rapidement, possiblement des items qui se chargent entre eux pour spam les sources chaudes, Ice Luge diamant ou 2 ammo peut descendre à 2s le cd de ces dernières, les enchantements freeze sur des items non freeze peuvent être bons

Les items freeze qui target beaucoup d'items sont très bons avec hot spring.

Les étiquettes

  • Moteur : Presque toujours là, mais remplaçable.
  • Key : Rare, mais quand il est là, ça gagne.
