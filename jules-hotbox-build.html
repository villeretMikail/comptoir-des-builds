Jules Hotbox build

1 run: 7 wins.

Open this build in the interactive tool

The core

  • Imu: With enough Slow and Burn scaling, it hits really hard.

Variant 1: Hot Box

Boite chaude pour boost Imu à fond, et curry qui cast souvent si suffisamment de slow, très fort avec le skill Coma alimentaire, skill pour ajouter du slow recommandé car sinon ça peut être parfois trop lent à scale

What it adds:

  • Curry · Engine: A great pick to sit next to the Hot Box, given how fast it fires when you rain down Slow.
  • Hot Box · Engine: It boosts adjacent Burn items. With the Heavy enchantment it can charge even faster and give a LOT of Burn.

Flex for this variant:

  • Hot Sauce: Multicast 3 when placed well; it can deal a lot of Burn next to the Box.
  • Honeycomb: 3 Slows fairly quickly; fits the build well.
  • Honey Jar: Procs two Slows in exchange for a bit of Heal; very good if you get it.
  • Boar Roast: Two Slows, one of them on itself, in exchange for Max Health on each Slow or Burn; fits the build very well.
  • Pumpkin: A great source of Slow and scaling.
  • Marbles: Slow.

Example board: Honeycomb, Imu, Hot Box, Curry, Honey Jar, Boar Roast, Pumpkin.

Item roles

  • Engine: Almost always there, but replaceable.
