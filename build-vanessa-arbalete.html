Arbalète et du haste !

1 run : 10 victoires.

Ouvrir ce build dans l’outil

Le core

  • Arbalest · Obligatoire

Variante 1 : Tools captain's quarter

Quartier du capitaine haste tous les tools ET recharge, avec assez de tool, on choppe du haste sur beaucoup d'items en même temps, d'autant plus que plein de tools ont comme effet de pouvoir haste, c'est donc une bonne option pour allier haste et recharge pour l'arbalète.

Elle ajoute :

  • Astrolabe
  • Dive Weights
  • Captain's Wheel · Moteur
  • Captain's Quarters · Moteur

Peut rentrer dans cette variante :

  • Beach Ball · Option
  • Rowboat · Option
  • Energy Potion · Option

Board type : Astrolabe, Dive Weights, Captain's Quarters, Captain's Wheel, Arbalest.

Comment le jouer

L'arbalète profite du haste pour stack des dégâts, l'objectif est de trouver une combinaison d'objets qui rapportent beaucoup de haste pour qu'elle stack le plus vite possible et qu'elle ait besoin de peu de hits pour kill, plusieurs façons d'arriver à cet objectif sont possibles, en plus des variantes qui s'ajouteront ici, ne pas hésiter à tenter des trucs.

Les étiquettes

  • Obligatoire : Le build n'existe pas sans.
  • Moteur : Presque toujours là, mais remplaçable.
  • Option : Une option quand il reste de la place.
