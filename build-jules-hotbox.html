1 run : 7 victoires.

Ouvrir ce build dans l’outil

Le core

  • Imu : Avec suffisamment de slow et de scaling sur son burn, elle envoie de la patate

Variante 1 : Boîte chaude

Boite chaude pour boost Imu à fond, et curry qui cast souvent si suffisamment de slow, très fort avec le skill Coma alimentaire, skill pour ajouter du slow recommandé car sinon ça peut être parfois trop lent à scale

Elle ajoute :

  • Curry · Moteur : Très bon candidat pour être à côté de la Boîte chaude vu sa cadence de tir quand on fait pleuvoir le slow
  • Hot Box · Moteur : Elle booste les items de burn adjacents, quand elle est enchantée Heavy elle peut se charger encore plus rapidement et donner BEAUCOUP de burn

Peut rentrer dans cette variante :

  • Hot Sauce : Multicast 3 si bien placé, peut faire beaucoup de burn si à côté de la Box
  • Honeycomb : 3 slow assez rapidement, rentre bien dans le build
  • Honey Jar : Proc deux slow en échange d'un peu de heal, très bon si on le choppe
  • Boar Roast : Deux slow, dont un sur lui-même, en échange de PV max, à chaque slow ou burn, rentre très bien dans le build
  • Pumpkin : Très bonne source de slow/scaling
  • Marbles : Du slow

Board type : Honeycomb, Imu, Hot Box, Curry, Honey Jar, Boar Roast, Pumpkin.

Les étiquettes

  • Moteur : Presque toujours là, mais remplaçable.
