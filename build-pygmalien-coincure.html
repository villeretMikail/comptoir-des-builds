The Bazaar · Pygmalien

Build Coincure — Pygmalien

Monter la value de Coincure en combat (et hors combat si possible) pour faire profiter aux armes et aux items de heal de gros bonus, avoir des items de heal et de dégâts rapides est souvent rentable.

Testé au patch 19.2 · 1 run : 10 victoires.

Ces objets sont des exemples : aucune game ne se ressemble, et des infinités de variations peuvent exister.

Ouvrir ce build dans l’outil

Le core

  • Coincure

Variante 1 : Jouets

Avec la variante jouet le but est de trouver un yoyo, puis des jouets qui l'aident à taper rapidement pour qu'il profite un max des dégâts que lui donne Coincure, les items de heal rapide sont évidemment primordiaux, et l'enchant heal sur le yoyo est un absolute banger, Piggles Board semble aussi permettre de bonnes boucles de dégats et de heal si on le choppe.

Obtenir un tag jouet sur bandages ou autres items de soin est très bon aussi.

Elle ajoute :

  • Bandages · Moteur
  • Kukri · Moteur
  • Yo-Yo · Moteur
  • Piggles Launcher · Moteur

Peut rentrer dans cette variante :

  • Model Ship : Très bon avec yo-yo
  • Marbles : Très bon depuis que Coincure profite aussi du slow
  • Haladie
  • Piggles Board : Charge les jouets entre eux pour plus de proc
  • Premium Green Piggles : Jouet + heal rapide

Peut rentrer

Des objets qui vont avec l'idée du build.

  • Plantes Grasses (Succulents)
  • PenFT

Comment le jouer

Chercher des items de heal et de dégâts rapides, les items qui font les deux sont excellents, enchant heal sur item damage (ou inversement) apporte beaucoup de value, des items qui rajoutent de la value flat peuvent rentrer dans le build également.

Kukri possède les deux de base, il est donc souvent excellent dans ce genre de build.

Les étiquettes

  • Moteur : Presque toujours là, mais remplaçable.
