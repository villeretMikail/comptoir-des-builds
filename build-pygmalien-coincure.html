Build Coincure — Pygmalien

monter la value de coincure en combat ( et hors combat si possible) pour faire profiter aux armes et aux items de heals de gros bonus, avoir des items de heal et de dégat rapides est souvent rentable

1 run : 10 victoires.

Ouvrir ce build dans l’outil

Le core

  • Coincure · Obligatoire

Variante 1 : Jouets

Avec la variante jouet le but est de trouver un yoyo, puis des jouets qui l'aident à taper rapidement pour qu'il profite un max des déggâts que lui donnent coincure, les items de heal rapide sont évidemment primordiaux, et l'enchant heal sur le yoyo est un absolute banger, piggles board semble aussi permettre de bonnes boucles de dégats et de heal si on le choppe.

obtenir un tag jouet sur bandages ou autre items de soin est très bon aussi

Elle ajoute :

  • Bandages · Moteur
  • Kukri · Moteur
  • Yo-Yo · Moteur
  • Piggles Launcher · Moteur

Peut rentrer dans cette variante :

  • Model Ship · Option : très bon avec yo-yo
  • Marbles · Option : très bon depuis que coincure profite aussi du slow
  • Haladie · Option
  • Piggles Board · Option : charge les jouets entre eux pour plus de proc
  • Premium Green Piggles · Option : jouet + heal rapide

Peut rentrer

Des objets qui se glissent dans le build à la place d’un autre.

  • Plantes Grasses (Succulents) · Option
  • PenFT · Option

Comment le jouer

chercher des items de heal et de dégats rapides, les items qui font les deux sont excellent, enchant heal sur item damage ( ou inversement) apporte beaucoup de value, des items qui rajoute de la value flat peuvent rentrer dans le build également.

Kukri possède les deux de base, il est donc souvent excellent dans ce genre de build

Les étiquettes

  • Obligatoire : Le build n'existe pas sans.
  • Moteur : Presque toujours là, mais remplaçable.
  • Option : Une option quand il reste de la place.
