The core

  • Jetbike

Variant 1: Double Glider

The Jetbike benefits a lot from fast Flying items: the two Stealth Gliders and the Cirrus Feather can charge it quickly. It can lack damage, so go for skills that help it kill fast.

What it adds:

  • Stealth Glider · Engine, ×2
  • Cirrus Feather · Engine

Example board: Cirrus Feather, Jetbike, Stealth Glider, Stealth Glider.

How to play it

Find the Jetbike, then Flying items, and try to make fast loops by using your Flying items often. Stealth Glider is a good addition because it reduces the cooldown of Flying items.

Item roles

  • Engine: Almost always there, but replaceable.
